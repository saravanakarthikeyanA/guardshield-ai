# guardshield-ai
🛡️ GuardShield-3B is a lightweight, low-latency (&lt;45ms) content safety and policy enforcement guardrail fine-tuned from Qwen2.5-3B-Instruct with Unsloth QLoRA. Features a 5-class safety hazard taxonomy, structured JSON enforcement decisions, GGUF edge quantization, and high adversarial recall for production LLM pipelines.
